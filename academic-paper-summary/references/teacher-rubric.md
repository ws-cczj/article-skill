# 老师要求、范例与用户偏好

区分来源，不把示例偶然做法当成老师原话。

| 项目 | 老师指导文件 | 用户已明确的执行方式 |
|---|---|---|
| 题目 | 简要，最好吸引眼球 | 公众号式简短学术标题，突出有依据的发现、对比或权衡；允许自然设问，不夸张或捏造 |
| 背景 | 2–3段 | 问题、已有不足、本文研究目的 |
| 方法 | 材料制备、实验与表征方法；配图 | 有制备写材料制备，确有材料或试样设计才加入设计；实验、表征、数值工作按实际有无归类，具体技术及用途写在正文 |
| 第三部分 | 关键图文解析，结合结论性图表解释关键结论，至少5个图 | 使用成功范例的“主要结论”；小标题写具体结果，附对应原图与解释，并按真实证据关系递进 |
| 创新点 | 简要3点 | 有原文依据的3项贡献，每点通常2–3句，写具体贡献、区别与意义，不复制示例中4–5项的数量 |
| 引用格式 | 原文引用 | 核对目标论文身份，不复制模板的引用 |

历史模板曾要求第三部分至少5个图；用户最新要求优先：主要结论至少5项，按文献研究流程和发现逻辑组织。图片服务于各项关键结论，选够说明内容的图即可，不再沿用总图数或每项图数配额。正文可详细展开，不固定六项，也不能编造或拆句凑条。

范例值得学习的是专业标题、方法分类、结果陈述、图文支撑和参数选择，不意味着其中所有数字、解释、引用与排版均正确。

用户最新图文要求：图号按总结实际出现顺序从图1连续编号，方法与结论共用序列，题名截图不计。研究方法至少配一张图，不限于原文专门的方法图解；仅原文完全没有图时省略。结合原图注、正文子图引用和布局判定真实子图，不把测点、区域或圈号一律当作子图。这些要求覆盖旧版允许沿用原文图号的规则。

写法见 [example-writing-patterns.md](example-writing-patterns.md)，图片处理见 [figure-analysis.md](figure-analysis.md)。

用户已指定Word字体和字号，作为交付硬性要求，详见 [output-formats.md](output-formats.md) 的格式表；覆盖旧版默认字体及公众号样式。

用户最新组织要求：所有制备环节集中介绍，其余实验、表征、模拟和数据处理集中介绍；主要结论至少5项（不固定六项），创新点每点稍作展开但不空泛扩写。该条属于用户补充，不是老师附件原句。

最新呈现要求：中文题目下放原论文题名信息截图，不再手排作者与期刊开头；方法简述，两节小项分别从1、2、3编号；结论图只截必要图像主体，不含图外原始Fig. X及英文图注。最新字体字号和段落设置统一以output-formats.md为准。

最新开头截图要求：完整包含作者单位和地址，保持原文英文排版；地址不是仅指DOI。标题在准确前提下兼顾公众号阅读吸引力，不再默认论文式长标题。
