# 流程检查索引

这是SKILL.md单一流程的导航，不是额外一轮检查。按阶段使用相应文件；同一证据、判断和问题只维护一处，记录与成稿实际版本对应。程序通过不证明科学事实或文风正确。

| 检查时点 | 需要确认 | 详细依据与已有记录 |
|---|---|---|
| 阅读后 | 原文关键段落已读清；分组、条件、发现及解释可定位；主线回答研究问题 | reading-synthesis.md；memory/synthesis.md |
| 完整文字稿后、首次构建前 | 每节围绕认识展开；关键数值、比较范围和因果强度成立；创新有增量依据；图注含义正确 | content-self-review.md；content-claims.json记录逐项核查，content-review.md记录整稿判断与修订 |
| 裁片入稿前 | 首页含完整作者单位地址且不含关键词/摘要；结果图四边、标签、图例完整，无原始图注或旁栏正文 | figure-analysis.md；工具生成的裁片核查记录，错误登记reject-crop |
| Word生成后 | 实际文字、符号和图片未被转换改变；结构、样式、可读性及图注邻接正确 | output-formats.md；结构检查及渲染结果。正常留白不返工 |
| 交付前 | 已发现的问题已修正并回核；记录和依赖匹配当前成稿 | memory-workflow.md；check --artifact与last-delivery.json |

不另写证据表、固定两段“通过总结”或重复自审文件。已有记录能定位就引用它；发现问题只修订对应输入与相关记录。题目、提纲和图片选择均服从已经读懂的研究主线，不先定图片数量再安排结论。

仅结构检查通过、裁图无告警或memory中没有问题，都不能代替实际阅读与视觉检查。内容未核实不进入正式排版，严重裁切、错对象或关键争议未处理不宣称交付通过；无法完成核查时如实说明限制。
