# article-skill

用于“总结文献”的技能说明。

## 目标

输入一篇文献内容（标题、摘要、方法、实验、结论等），输出结构化总结，帮助快速理解论文贡献与局限。

## 推荐输出结构

1. **基本信息**：标题、作者、年份、研究领域  
2. **研究问题**：论文要解决的核心问题  
3. **核心方法**：关键思路、模型/算法、与已有方法差异  
4. **实验与结果**：数据集、评价指标、主要结果  
5. **主要贡献**：2-4 条可复用结论  
6. **局限与改进方向**：当前方法不足与潜在优化点  
7. **一句话总结**：面向非专业读者的简洁描述

## 使用建议

- 优先基于原文内容总结，不编造缺失信息。  
- 对不确定信息明确标注“文中未说明”或“需进一步确认”。  
- 需要对比多篇文献时，按同一结构并排总结，便于横向比较。
